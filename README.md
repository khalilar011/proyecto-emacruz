# Proyecto EMACRUZ - Gestión de Residuos

## Descripción

Este repositorio corresponde al proyecto universitario desarrollado en torno a EMACRUZ y la gestión de residuos sólidos en Santa Cruz de la Sierra.

El proyecto busca analizar los datos disponibles relacionados con la recolección y gestión de residuos utilizando herramientas de ciencia de datos e inteligencia de negocios, con el objetivo de identificar patrones, problemáticas y posibles oportunidades de mejora.

## Objetivo general

Analizar información relacionada con la gestión y recolección de residuos sólidos de EMACRUZ mediante herramientas de ciencia de datos e inteligencia de negocios.

## Objetivos específicos

- Organizar y centralizar los datos disponibles del proyecto.
- Analizar información relacionada con la recolección de residuos.
- Identificar patrones y posibles problemáticas.
- Aplicar herramientas de análisis de datos.
- Generar información útil para futuras propuestas de mejora.

## Base de datos

La carpeta `data/` contiene los datos disponibles actualmente para el desarrollo del proyecto. Estos datos serán utilizados como fuente para los análisis, modelos y visualizaciones que se desarrollarán posteriormente.

Archivo disponible:

- `Base_Emacruz_sectores_y_frecuencias.xlsx`

El archivo se conserva en su formato original, sin modificaciones en su contenido.
